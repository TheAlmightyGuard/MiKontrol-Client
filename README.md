# Mikoto Management

The Mikoto Dashboard is the web-server based central for general moderation and automation for discord servers.\
This web-server was made by Python and FastAPI

Hosted on Render, it provides uptime for the Mikoto Management and hosts the API web-server for Mikoto Dashboard.\
It is capable of user-friendly moderation, customization, custom command creation and much more!
